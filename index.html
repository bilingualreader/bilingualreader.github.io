从 Edge 商店安装

支持 Microsoft Edge。Chrome 版本准备中

快速上手（3 步）

  1. 安装插件后，打开任意英文网页
  2. 每段英文下方会自动出现中文译文，原文保持不动，双语对照阅读
  3. 不想翻译时，点页面右侧的悬浮球 译 一键关闭，译文立刻移除

开关与设置

开启 / 关闭翻译三种方式任选：点页面右侧悬浮球 译（蓝色=开启 译 灰色=关闭）；点浏览器工具栏的插件图标拨动开关；快捷键 Alt + Z
切换翻译方向点工具栏插件图标 → 选「英文 → 中文」（默认）或「中文 → 英文」
移动悬浮球按住球拖到任意位置,松手自动吸附到最近的一侧边缘,位置会被记住
悬浮球挡住内容静置几秒后它会自动半隐藏到边缘;鼠标靠近立刻完整显示
隐藏悬浮球插件弹窗里取消勾选「在网页右侧显示悬浮球开关」
视频字幕翻译看视频时字幕会自动翻译,中文显示在整行字幕正下方;可在弹窗里关闭
关闭后页面所有译文自动移除，网页恢复原样，不留任何痕迹

常见问题

某个网页没有出现译文？

先看悬浮球颜色：灰色代表翻译已关闭，点一下变蓝即可。若球是蓝色仍无译文，可能该页面没有可翻译的英文段落（纯中文页面不会被翻译），或内容在特殊封闭组件里（少数网站限制，属已知情况）。

译文显示「(翻译失败)」？

多为网络瞬时波动，刷新页面即可恢复。鼠标悬停在提示文字上可查看具体原因。

显示「今日免费额度已用完」？

免费版每天可翻译 10,000 字符，次日 0 点自动恢复。阅读量大的用户建议升级 Pro，每月 50 万字符额度（约 100 篇英文文章）。

为什么代码块、网址没有被翻译？

这是有意设计：程序代码、纯链接、输入框内容翻译后反而影响使用，插件会智能跳过它们。

翻译内容会被收集吗？

插件仅将需要翻译的网页文本发送到翻译服务生成译文，不收集浏览历史与个人信息，设置只保存在你的浏览器本地。详见隐私政策。

支持哪些浏览器？

Chrome、Edge 及其他 Chromium 内核浏览器（360、QQ 浏览器等）。
